ONE SMALL COMMAND

이제 rescue만 기억하세요.

Mac 터미널과 모바일 Termius에서 같은 명령으로 점검합니다.
Mac에서는 Rescue 아이콘으로 네이티브 앱을 열 수 있습니다.

rescue
rescue gui --web
이 웹 화면 열기
rescue watch
터미널에서 메모리 변화 관찰
rescue remote-check
Tailscale·SSH 연결 준비 확인
rescue gui --stop
Rescue 모니터만 종료
RECOVER & REINSTALL

Orca가 멈춰도, 연결은 따로.

모바일 Tailscale → Termius → 내 Mac에 접속한 뒤 rescue를 실행하세요. 메모리가 큰 작업을 확인하고, 끝난 개발 그룹부터 정리하면 됩니다.

새 Mac / 포맷 후 복원

mac-rescue 저장소를 복원한 다음 저장소 폴더에서 아래 명령을 실행합니다. CLI와 앱 아이콘이 함께 설치됩니다. SSH와 Tailscale 연결은 새 Mac에서 다시 설정해야 합니다.

python3 scripts/install-rescue.py

소스의 원격 보관 여부는 Git 커밋·푸시 상태에 달려 있습니다. 이 화면이 백업을 대신하지 않습니다.

Rescue · 로컬에서 확인하고, 직접 선택하세요.
