# 083-04: 공개 대비 개인 설정 분리

## 변경

실제 Mac 접속 정보를 공개 문서에서 제거하고 `.env.local`로 분리했다. 예시는 모두
마스킹하며 접속 별칭·SSH 사용자·Tailscale IP·포트만 지원한다. 비밀번호/개인키는 관리하지 않는다.
개인 값이 필요하지 않은 기기 모델·운영 권한 상태·내부 작업 링크는 문서에서 일반화했다.

설정은 셸로 실행하지 않고 표준 라이브러리로 파싱한다. 허용 키·형식·IP·포트를 검증하고 오류에
실값을 출력하지 않는다. 현재 Tailscale IP가 보관 값과 다르면 현재 Mac 주소를 우선하고 안내한다.
`rescue config`는 마스킹된 값만 출력한다.

설치기는 설정을 `~/.config/rescue/.env.local`에 0600, 디렉터리는 0700으로 저장한다.
앱 번들과 버전별 코드에는 개인 값이 들어가지 않는다. 설정이 없는 설치는 기존 값을 보존한다.

## 검증

- Red: 설정 모듈 없음, 개인 설정 분리 설치/잘못된 설정 사전 거부 실패 확인
- Green: 파서·마스킹·우선순위·명시 파일·기기 변경·오류 마스킹 테스트 6개
- 설치기: 권한·번들 제외·설정 검증을 포함한 5개 테스트
- 기존 CLI 14개, GUI 7개, 네이티브 통신 3개와 함께 전체 35개 통과
- 실제 `.env.local`은 Git 제외와 0600 권한 확인, 값은 로그에 기록하지 않음

## Git 기록과 동기화

Git 작성자는 이 저장소에만 공개용 이름과 GitHub noreply 이메일을 설정한다.
수정 커밋만 추가해도 이전 이력의 개인정보는 사라지지 않는다. 기존 원격 참조 교체와 공개
전환은 별도 판단이 필요하며, 이미 전송된 객체의 GitHub 캐시 삭제를 로컬 도구가 보장하지 않는다.

Obsidian 동기화 대상은 `projects/tools/mac-rescue/env.md`의 Root/.env.local이다.
프로젝트의 코드 커밋과 실제 환경값을 보관하는 비공개 vault 커밋은 분리한다.
