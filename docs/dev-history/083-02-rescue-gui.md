# 083-02: Rescue GUI와 재설치 가능한 배포 구조

관련: [계획](../plan/083-mac-rescue.md), [사용 안내](../mac-rescue.md).

## [DEV] 개발 — 2026-09-08

### 결과

표준 라이브러리 HTTP 서버와 정적 HTML/CSS/JS로 PC GUI를 구현했다. 별도 패키지·Electron·
공개 서버·로그인 자동 실행 서비스는 추가하지 않았다. 기존 개발/자동화 그룹 정책을 재사용한다.
고정 포트·인증 없는 kill API를 피하고 loopback 바인딩, Host/Origin 검사, 실행별 토큰,
서버 보관 일회용 종료 미리보기, 60초 만료와 PID identity 검증을 적용했다.

설치기는 버전별 소스 복사, current 링크, `rescue`·`mac-rescue` 실행기, Rescue.app과 아이콘,
명시된 PATH 블록을 만든다. 반복 설치로 사용자 설정이 중복되지 않고 다른 프로그램을 보호한다.
사용자 홈에 설치한 복사본은 백업 원본으로 취급하지 않는다. 원격 Git 보관은 미완료다.

### 디자인·사용성

상태 요약 → 메모리순 실행 목록 → 그룹 상세 → 종료 영향 확인으로 연결한다. 프로젝트 이름을
먼저 보여주고 전체 경로는 상세에 둔다. stale 표시는 단정 대신 검토 근거로 제공한다.
차분한 녹색, 경고 황색, 종료에만 붉은색을 사용하며 밝게/어둡게/시스템 테마를 지원한다.
숫자는 tabular-nums로 고정하고 키보드 포커스·dialog·검색·빈 결과·오류·모바일 화면을 처리한다.

### 검증·수정

- 기존 CLI 테스트 14개, GUI 정책/HTTP 경계 테스트 7개, 설치기 테스트 3개 통과
- 전체 `node scripts/verify.mjs` 통과(exit 0), harness parity divergence 0
- GUI Red: 구현 모듈 없음으로 실패 확인 후 Green
- 실제 브라우저: 검색·빈 결과·정렬·필터·상세·확인 전 버튼 비활성 검증
- 직접 만든 Node 테스트 서버만 GUI에서 확인 문구 입력 후 SIGTERM 종료 성공
- 사용자 작업 서버/Chrome은 검증 목적으로 종료하지 않음
- 자동 새로고침이 종료 미리보기 클릭을 무시할 수 있어 조회 상태와 변경 상태를 분리
- 390px/1440px 및 light/dark 렌더 확인, 긴 테이블은 내부 가로 스크롤 유지
- 이전 자동화 세션의 대기 명령이 지연되어 해당 검수 세션을 닫고 등록된 브라우저 도구로 검증 완료
- 모바일 SSH 연결/기존 CLI 실행은 사용자 스크린샷으로 확인 완료

### 남은 한계

시스템·다른 사용자 프로세스의 메모리는 권한에 따라 일부 조회되지 않는다. GUI 종료 대상은
감지된 개발/자동화 그룹에 한정한다. Mac 전체 멈춤과 FileVault 재부팅 잠금은 별도이며,
원격 저장소에 push하기 전에는 포맷 대비 백업 완료로 보고하지 않는다.
